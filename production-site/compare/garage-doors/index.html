01

Replacing a door

Start with the opening size, door style and photos taken from inside and outside. Ask whether the proposed price includes removal of the old door, fitting, automation and any work needed around the opening.

02

Repairing an existing system

Describe whether the door is noisy, moves unevenly, stops partway or does not respond to the remote. A door problem and a motor problem can require different work. Featherbleu offers both installation and repairs, so you can discuss the symptoms before deciding on replacement.

03

The Featherbleu fit

Choose Featherbleu when you want to discuss the door and its automation together with the owners. The project gallery gives you examples to help explain the finish and style you have in mind.

Before you decide

Three questions worth asking.

Use the same questions with every provider so the answers are easier to compare.

  1. Does this quote include the door, fitting and automation?
  2. What existing components will be retained or replaced?
  3. Who handles installation issues and product warranty enquiries?
